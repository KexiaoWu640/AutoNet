调网通 AutoNet 使用说明
================

一、准备
适用于 Windows 7 SP1 x64。AutoNet.exe、devices.csv、links.csv 放在同一文件夹。
电脑需能访问交换机管理 IP，设备需开启 SSH。

devices.csv 表头：id,ip,type
填写设备 ID、管理 IP、类型。华三填 h3c，华为填 huawei；不需要 name 列。

links.csv 表头：input_ip,port,output_ip
填写当前交换机 IP、通往下一台交换机的端口、下一台交换机 IP。
两端 IP 必须出现在设备表。不要填写最终连接终端的接入口。

二、使用
1. 修改两个 CSV。支持 UTF-8、GBK/GB18030、带 BOM 的 UTF-16。
2. 双击 AutoNet.exe，输入部分 IP 或设备 ID，展开列表选择起始设备。
3. 填写 MAC、目标 VLAN、SSH 用户名和密码。
4. 点击“开始调网”，等待下方结果。
修改 CSV 后点“重载 CSV”。完整 IP、设备 ID 或唯一匹配可直接开始。

保存账号：填写账号名称，点“添加 / 保存”；以后选账号再点“调用”。
账号管理默认折叠，点击“展开已存账号与账号管理”即可显示。
同名会更新。账号保存在 credentials.dat，换电脑或 Windows 用户后需重新保存。

三、结果
调网成功：本次修改后，配置回读、保存、ARP 验证均通过。
网络已调通：原配置已正确，跳过重复修改，保存和 ARP 验证通过。
保存失败或未收到成功确认：配置已生效，但保存未确认，请查看日志。
配置已校验并保存，但 ARP 验证失败：检查终端是否在线并产生流量。
配置校验失败：回读 VLAN 或静态 MAC 不符，未执行保存。
其他失败：按提示检查 SSH、MAC、设备命令或读取结果。

“网络已调通”不代替互联网或业务系统测试。最多追踪 5 台设备，ARP 最多检查两次。
只对最终 GE/GigabitEthernet 接入口配置、保存。保存会写入设备整份当前运行配置。
华三使用 save force，华为使用 save 并处理确认提示。

四、日志和诊断
日志在 logs 文件夹，不记录密码，但包含现场设备信息，请勿公开上传。
运行后点击“运行记录”右侧的“查看日志”可直接打开；运行中打开的日志需在结束后重新打开查看完整内容。
本地输入诊断不连接网络，命令行建议使用调试版：
AutoNet-debug.exe input-test-safe
AutoNet-debug.exe input-test
safe 模式只显示密码长度；普通模式会明文显示密码，仅限开发诊断。

源码仓库的 README.md 包含完整构建说明。构建必须使用 Go 1.20.14。
当前 SSH 不校验主机密钥，请在可信管理网络使用。
